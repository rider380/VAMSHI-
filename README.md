# VAMSHI — 

A responsive, premium dark-themed personal portfolio built with HTML, CSS and JavaScript. It can be hosted free on GitHub Pages and does not require a build step.

## Add your own photos

Put your photos in the `images` folder with these exact filenames:
- `vamshi-1.jpg`
- `vamshi-2.jpg`
- `vamshi-3.jpg`
- `vamshi-4.jpg`

Your earlier chat uploads are not automatically embedded in this ZIP. Add the original image files you want to use. You can also change the image filenames and their `src` paths in `index.html`.

## Publish using GitHub Pages

1. Extract this ZIP on your computer.
2. Create a new GitHub repository, for example `vamshi-portfolio`.
3. Upload all files and folders from the extracted project into the repository's root (do not upload only the ZIP file).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to publish; the website URL appears on that same page.
